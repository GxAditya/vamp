# @gxaditya/vamp-schema

Canonical SongSchemaV1 JSON Schema, generated TypeScript and Python types, validation and normalization.

Part of the [Vamp](https://github.com/GxAditya/vamp) monorepo — a fully local, headless music engine for coding agents. See the repo README and docs for setup, the song schema guide, and provisioning FluidSynth for sampled rendering.
